# Online Appendix — Pseudo Real-Time Nowcasting of Korean Employment

This repository hosts the online appendix to

> Hyunjin Choo and Yeonhee Lee. **Pseudo Real-Time Nowcasting of Korean Employment: A Four-Part Test of Sentiment Signals with Sector-Scoped Evidence.** In *Proceedings of the IEEE International Conference on Data Mining Workshops (ICDMW), HDM'26*, 2026 (to appear).

## Contents

| File | Description |
|---|---|
| `online_appendix.pdf` | Tables A1–A7 referenced in the paper, with an overview and notes on individual tables. |

Tables A1–A7 expose numbers summarized in Sections V–VI of the paper; they add no result beyond it.
Section references in the appendix (e.g., "Sect. III") refer to the paper.
